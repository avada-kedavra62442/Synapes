# SynApes — NRL HyperDrive 2026

A responsive, dark-mode team website for SynApes, a 10-student team competing in NRL 2026 Delhi Regionals in the HyperDrive game.

## Design
- Midnight navy interface with racing orange, electric cyan, and steel-blue accents
- Responsive navigation and mobile layout
- Custom inline SVG robot illustration
- Team overview, HyperDrive focus, and school representation sections
- Lightweight HTML, CSS, and JavaScript; no build step or dependencies

## Deploy on Vercel
1. Import this repository into Vercel.
2. Choose **Other** as the framework preset if prompted.
3. Leave the build command and output directory empty/default; the root `index.html` is served as a static site.
4. Deploy.
