# SynApes — NRL 2026 / HyperDrive

A React + Vite team website for SynApes, a 10-student robotics team from CM Shri Schools in Dwarka, competing in NRL 2026 Delhi Regionals (HyperDrive).

## Stack
- React
- Vite
- Framer Motion
- Lucide React
- Custom responsive CSS

## Run locally
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
```

## Deploy to Vercel
1. Open [Vercel](https://vercel.com/) and import `avada-kedavra62442/Synapes` from GitHub.
2. Vercel should detect **Vite** automatically.
3. Framework preset: **Vite**.
4. Build command: `npm run build`.
5. Output directory: `dist`.
6. Click **Deploy**.

No environment variables are required. GitHub pushes to the connected production branch will trigger deployments automatically.

## Content notes
The site uses the confirmed team totals and school split. Individual student names, robot specifications, results, and competition dates are intentionally not invented.
